# Dynamic Pricing System

ML-система прогнозирования спроса и динамического ценообразования для российского ритейла на основе исторических данных продаж компании **1С**.

Проект разрабатывается в рамках выпускной квалификационной работы (РТУ МИРЭА).

Система включает:

- Модель прогнозирования спроса (Demand Forecasting)
- Модуль динамического ценообразования (Dynamic Pricing)

## Данные

Используется открытый датасет **Predict Future Sales** (1С), доступный на Kaggle:  
[Competition: Predict Future Sales](https://www.kaggle.com/c/competitive-data-science-predict-future-sales)

Датасет содержит:

- ежедневные продажи товаров (количество, цена);
- справочники товаров, категорий и магазинов;
- временные метки транзакций.

После предобработки данные агрегируются до месячного уровня:  
`shop_id | item_id | month | sales_qty | revenue | avg_price | main_category | super_category`

- жизненный цикл товаров.

Все графики автоматически сохраняются в `artifacts/figures/eda/`.

## Data Cleaning

Реализован полный пайплайн предобработки:

- объединение таблиц продаж, товаров, категорий, магазинов;
- преобразование дат и выделение месяца;
- проверка пропусков (отсутствуют);
- удаление дубликатов и некорректных значений;
- агрегация дневных продаж до месячного уровня;
- создание укрупнённых категорий (`main_category`, `super_category`);
- сохранение результата в **Apache Parquet** (`data/interim/monthly_sales.parquet`).

Parquet обеспечивает компактное хранение, сохранение типов и быстрое чтение.

## Feature Engineering

Реализован полный этап построения признаков для моделей прогнозирования спроса.

Созданы следующие группы признаков:

### Временные признаки

* лаги продаж за предыдущие **1, 2, 3, 6 и 12 месяцев**;
* циклическое кодирование месяца (`month_sin`, `month_cos`);
* календарные признаки (`is_winter`, `is_summer`, `days_in_month`).

### Скользящие статистики

* средние продажи за **3, 6 и 12 месяцев**;
* стандартное отклонение продаж за предыдущие периоды.

### Ценовые признаки

* цена товара;
* лаги цены;
* относительное изменение цены;
* скользящее среднее цены.

Итоговый датасет сохраняется в:

```
data/processed/model_dataset.parquet
```

Данный датасет используется на следующем этапе для обучения моделей машинного обучения.

## Модели прогнозирования спроса

### Baseline-модели

В качестве отправной точки были реализованы три базовых подхода к прогнозированию спроса.

| Модель | Описание |
|---------|----------|
| Naive (lag_1) | спрос следующего месяца принимается равным спросу предыдущего месяца |
| Seasonal Naive (lag_12) | спрос повторяет значение аналогичного месяца предыдущего года |
| Linear Regression | линейная регрессия на временных и ценовых признаках |

---

### Основные модели

В качестве основных моделей были реализованы и сравнены алгоритмы градиентного бустинга:

- CatBoost
- XGBoost

Обучение моделей выполнялось на обучающей выборке с использованием временной кросс-валидации (**TimeSeriesSplit**) с возрастающим окном (**Expanding Window Cross-Validation**), что исключает утечку информации из будущих периодов.

---

### Подбор гиперпараметров

Для автоматического поиска оптимальных гиперпараметров использовалась библиотека **Optuna**.

Подбирались следующие параметры моделей:

- learning_rate;
- depth / max_depth;
- iterations / n_estimators;
- регуляризация;
- параметры построения деревьев.

После завершения оптимизации модели переобучались на всей обучающей выборке и оценивались на трёх последних месяцах данных.

---

### Логирование экспериментов

Для отслеживания экспериментов использовалась библиотека **MLflow**.

Для каждого запуска автоматически сохраняются:

- значения гиперпараметров;
- метрики качества моделей;
- обученные модели;
- артефакты экспериментов.

Это обеспечивает воспроизводимость результатов и удобное сравнение различных конфигураций моделей.

Локальные данные MLflow хранятся в: mlflow.db

---

### Интерпретация модели

Для анализа работы модели использовалась библиотека **SHAP (SHapley Additive exPlanations)**.

Были построены:

- **SHAP Summary Plot** — глобальная важность признаков и направление их влияния на прогноз;
- **SHAP Force Plot** — объяснение предсказания модели для отдельного объекта.

Использование SHAP позволяет интерпретировать поведение модели и определить, какие признаки оказывают наибольшее влияние на прогноз спроса.

---

### Итоговое сравнение моделей

| Модель | Test MAE | Test RMSE | Test R² |
|--------|---------:|----------:|---------:|
| Seasonal Naive | 0.3416 | 1.6316 | -0.4316 |
| Naive (lag_1) | 0.2184 | 1.1035 | 0.3452 |
| Linear Regression | 0.2288 | 0.9682 | 0.4959 |
| XGBoost | **0.1555** | 0.8708 | 0.6383 |
| **CatBoost** | 0.1606 | **0.8685** | **0.6402** |

По сравнению с лучшей baseline-моделью (Linear Regression) использование градиентного бустинга позволило снизить значение RMSE более чем на **10%** и увеличить коэффициент детерминации **R²** с **0.496** до **0.640**.

---

### Выбранная модель

В качестве основной модели системы выбрана **CatBoost**.

Несмотря на немного лучшее значение MAE у XGBoost, модель CatBoost продемонстрировала лучшие значения **RMSE** и **R²**, что делает её более предпочтительной для задачи прогнозирования спроса.

Обученная модель сохраняется в:

```text
artifacts/models/
```

и используется на следующем этапе проекта для формирования рекомендаций по динамическому ценообразованию.

Важность признаков и метрики сохраняются в:

```text
artifacts/tables/
```

## Модуль динамического ценообразования

1. **Генерация кандидатов:** сетка цен вокруг текущей (±20%).
2. **Прогноз спроса** для каждого кандидата обученной моделью.
3. **Оптимизация:**
   - Линейная функция спроса `Q = a - b * P` (коэффициенты оцениваются моделью).
   - Целевая функция: максимизация прибыли / выручки.
   - Ограничения: min/max цена, соблюдение маржинальности.
4. **Результат:** рекомендованная цена для каждой пары товар–магазин на следующий месяц.
